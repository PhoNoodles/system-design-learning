# System Design Learning

Primary curriculum: [The System Design Primer](https://github.com/donnemartin/system-design-primer).

GitHub issues are the authoritative learning record. Read [LEARNING_PROTOCOL.md](LEARNING_PROTOCOL.md) before teaching; see [CURRICULUM.md](CURRICULUM.md) for ordered lesson IDs. Open issues are not yet mastered; closed issues require recorded assessment evidence. Resume the lowest unfinished prerequisite or the learner's explicitly chosen topic. Use issue comments to record each session, independent scores, gaps and next steps. No prior exposure is assumed to be mastery.
